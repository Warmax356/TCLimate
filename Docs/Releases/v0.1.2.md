# TCLimate v0.1.2 — Public Beta

A small maintenance update to the unofficial macOS menu bar companion for TCL Home air conditioners.

## Changed

- Each unit now shows its indoor temperature once, labelled "indoors" beside the target temperature, instead of also repeating it in the status line.

## Install

Requires macOS 14 or later and internet access. Open the DMG, drag TCLimate onto the Applications shortcut, eject the image, then open the app from Applications. A ZIP is also available. Replace any existing copy and keep only one installed copy. Saved sign-ins and Launch at Login carry over from v0.1.1.

Both the app and DMG are Developer ID–signed, notarized by Apple, and include stapled notarization tickets. Verify either download with the accompanying SHA256SUMS file if desired.

## Beta limitations

Live validation covers two Split AC units and a Pakistan account. Additional controls are unit-tested but have not all been physically exercised. Other models and regions are unverified. No local LAN control, direct Google OAuth, or MQTT live subscriptions.

This project uses unofficial APIs and is not affiliated with TCL. Report issues without passwords, tokens, device identifiers, or unredacted captures.
