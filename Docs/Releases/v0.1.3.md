# TCLimate v0.1.3 — Public Beta

A feature update to the unofficial macOS menu bar companion for TCL Home air conditioners.

## Added

- **Outdoor temperature** is shown under the indoor temperature on units that report it. Units that don't report one show nothing.
- **Health mode** switch under More, on units that report it.
- **Left/right swing** now sits in the same Airflow tile as up/down, with one menu for both.

## Changed

- Offline units no longer show their last known temperature, mode or controls, only that they are offline.
- The unit switcher shows each AC's full name from TCL Home.

## Install

Requires macOS 14 or later and internet access. Open the DMG, drag TCLimate onto the Applications shortcut, eject the image, then open the app from Applications. A ZIP is also available. Replace any existing copy and keep only one installed copy. Saved sign-ins and Launch at Login carry over from earlier versions.

Both the app and DMG are Developer ID–signed, notarized by Apple, and include stapled notarization tickets. Verify either download with the accompanying SHA256SUMS file if desired.

## Beta limitations

Live validation covers two Split AC units and a Pakistan account. Additional controls are unit-tested but have not all been physically exercised; Health mode in particular has not been toggled on a real unit. Other models and regions are unverified. No local LAN control, direct Google OAuth, or MQTT live subscriptions.

This project uses unofficial APIs and is not affiliated with TCL. Report issues without passwords, tokens, device identifiers, or unredacted captures.
