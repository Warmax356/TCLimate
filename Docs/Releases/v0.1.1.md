# TCLimate v0.1.1 — Public Beta

A maintenance update to the unofficial macOS menu bar companion for TCL Home air conditioners.

## Changed

- The app now uses the bundle identifier and Keychain service `io.loopbreak.TCLimate`.
- Saved sign-ins from v0.1.0 are migrated on first launch. macOS may ask once for permission to read the old Keychain item; if it is declined, sign in again.
- If you enabled Launch at Login in v0.1.0, turn it on again in v0.1.1 and remove the old entry from System Settings › General › Login Items.

## Install

Requires macOS 14 or later and internet access. Open the DMG, drag TCLimate onto the Applications shortcut, eject the image, then open the app from Applications. A ZIP is also available. Replace any existing v0.1.0 copy and keep only one installed copy.

Both the app and DMG are Developer ID–signed, notarized by Apple, and include stapled notarization tickets. Verify either download with the accompanying SHA256SUMS file if desired.

## Beta limitations

Live validation covers two Split AC units and a Pakistan account. Additional controls are unit-tested but have not all been physically exercised. Other models and regions are unverified. No local LAN control, direct Google OAuth, or MQTT live subscriptions.

This project uses unofficial APIs and is not affiliated with TCL. Report issues without passwords, tokens, device identifiers, or unredacted captures.
