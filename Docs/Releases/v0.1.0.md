# TCLimate v0.1.0 — Public Beta

The first public beta of TCLimate, an unofficial macOS menu bar companion for TCL Home air conditioners.

## Included

- Multiple ACs in one native SwiftUI panel with a unit switcher and animated airflow.
- Power, target temperature, and reported room temperature.
- Supported mode, fan, airflow, Eco, sleep, display, and beep controls.
- Daily electricity readings, today/yesterday/seven-day totals, and a seven-day chart. Missing readings remain separate from zero.
- Optional Keychain sign-in and launch at login.

## Install

Requires macOS 14 or later and internet access. The universal DMG and ZIP support Apple silicon and Intel Macs. Open the DMG, drag TCLimate onto the Applications shortcut, eject the image, then open the app from Applications. A ZIP is also available; unzip it and move TCLimate.app to Applications. Click the snowflake to sign in with your TCL email and TCL password. Google users must first set a TCL password in the official TCL Home app.

Both the app and DMG are Developer ID–signed, notarized by Apple, and include stapled notarization tickets. Gatekeeper validation passed before publication. Verify either download with the accompanying SHA256SUMS file if desired.

## Beta limitations

Live validation covers two Split AC units and a Pakistan account. Additional controls are unit-tested but have not all been physically exercised. Other models and regions are unverified. Cloud-reported confirmation is not independent physical observation. No local LAN control, direct Google OAuth, or MQTT live subscriptions.

This project uses unofficial APIs and is not affiliated with TCL. Report issues without passwords, tokens, device identifiers, or unredacted captures.
